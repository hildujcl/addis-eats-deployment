# ♡ Addis Eats — Ethiopian Food Ordering App

**Discover the taste of Ethiopia, one delicious meal at a time!**

Addis Eats is a modern, responsive food-ordering web application built with Next.js and React. Designed to make exploring Ethiopian cuisine simple and enjoyable, the platform allows users to discover traditional meals, browse food categories, manage their shopping cart, and submit demo orders through an intuitive interface.

## ✨ Key Features

- 🏠 **Beautiful Homepage** — An inviting introduction to the Addis Eats experience.
- 🍽️ **Food Menu** — Explore a selection of Ethiopian dishes with descriptions, images, and prices.
- 🔎 **Search and Filtering** — Find meals easily by name or category.
- 🛒 **Shopping Cart** — Add meals, adjust quantities, remove items, and view order totals.
- 💾 **Cart Persistence** — Keep cart information saved in the browser using localStorage.
- 📝 **Demo Checkout** — Enter customer and delivery details and submit a demonstration order.
- 📱 **Responsive Navigation** — Enjoy a consistent experience across desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   bash
   https://github.com/hildujcl/addis-eats-deployment
   

2. Navigate to the project directory:

   bash
   cd addis-eats
   

3. Install dependencies:

   bash
   npm install
   

4. Start the development server:

   bash
   npm run dev
   

5. Open your browser at:

   text
   http://localhost:3000
